# LLM_2026

- `lab_1/lab_1.ipynb` — классификация текстов с использованием Transformer embeddings.
- `lab_2/lab_2.ipynb` — дообучение decoder-only и encoder-decoder диалоговых моделей.
- `lab_3/lab_3.ipynb` — дообучение bi-encoder модели для семантического поиска.

Во всех ноутбуках код выполняется сверху вниз. Повторное долгое обучение по умолчанию отключено флагом `RUN_TRAINING = False`; сохранённые результаты и графики загружаются сразу.
